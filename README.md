# Rebar Relics

A new [Rebar](https://github.com/pylonmc/rebar) / [Pylon](https://github.com/pylonmc/pylon) addon bringing talismans, charms and magical artifacts to Minecraft.

**Status:** Early development — not yet production-ready. Work begins with three original, configurable talismans and expands into classic Slimefun-inspired talismans, relic bags, recipes, and new artifact systems.

Target initially: **Paper 26.3 / Java 25 / Rebar 0.45.0-26.3 / Pylon 0.43.0-26.3.** Pylon/Rebar addon APIs are experimental and may change. Never test development builds on an irreplaceable world.

Original implementation only. Existing plugin JARs are used for feature analysis; their proprietary code, textures and other bundled assets are not redistributed.
